# Overview

I'm a backend developer who spends most of my day in JavaScript and TypeScript, and I'm starting to learn R so I can work with data in a language built for it. This project is my first step: getting R set up, running a script from the terminal, and publishing the code the same way I'll publish everything else I build while learning.

The program prints the classic "Hello World" message, then greets the world in English, Portuguese and Yoruba. Those are the three languages I use in my everyday life. It's tiny, but it already uses a named vector, a for loop and formatted output, which gave me a first look at how R handles strings and data.

My purpose for writing this was to confirm that my R development environment works from start to finish and to get comfortable with the workflow of writing code, documenting it, recording a demo and publishing it to GitHub.

[Software Demo Video](http://youtube.link.goes.here)

# Development Environment

I wrote the code in Visual Studio Code with the R extension installed, and I ran it from the terminal with Rscript. I used Git for version control and GitHub to host the repository.

The program is written in R, a language designed for statistics and data analysis. It uses only base R, so there are no packages to install.
